# MATCHPULSE COLLECTOR ⚽

Отделна тестова лаборатория за футболни данни. **Основният [MATCHPULSE](https://github.com/planenp993/matchpulse-auto) не се променя от този проект.**

## Какво има във версия 0.1

- Програма и резултати от четири първенства: Англия (Висша лига), Германия (Бундеслига), Испания (Ла Лига), Италия (Серия А).
- Източник: [OpenFootball football.json](https://github.com/openfootball/football.json), CC0. Не е официален live feed и няма гаранции за пълнота или моментална актуалност.
- Кодът е в scripts/collector.py, автоматичният график е в .github/workflows/collect.yml.
- При успешен опит файлът data/latest.json се обновява автоматично два пъти дневно чрез GitHub Actions. Първото качване също стартира събиране.
- Всяка среща има ID, лига, дата, отбори, час и резултат (ако е наличен).
- Липсващите удари, xG, корнери и картони **не се попълват с измислени числа**.

## SofaScore

**Няма включено автоматично теглене от SofaScore.** По-късно, след проверка на разрешен достъп, можем да добавим статистически вход. Опционалният аргумент --stats-file позволява внос на изрично разрешени, предоставени JSON данни с посочен източник. Не се ползва заобикаляне на ограничения.

## За телефон

Не е нужно да инсталираш програми. Отвори [Actions](https://github.com/planenp993/matchpulse-collector/actions) и провери „Collect OpenFootball Data“. Първият резултат трябва да се появи в [data/latest.json](https://github.com/planenp993/matchpulse-collector/blob/main/data/latest.json), след като автоматичното изпълнение успее.

## Бъдещо обединяване

След тестване ще добавим **еднопосочен, проверяван импорт** към главната база MATCHPULSE. Ще проверяваме имената на отборите, датите, произхода и дублиранията. До тогава двата проекта остават независими.

Технически: Python 3.12, само стандартна библиотека; проверка: python -m unittest discover -s tests -v.
